# L字テロップ 設定・管理画面 仕様書

> **Version**: 1.0  
> **Date**: 2026-08-24  
> **フレームワーク**: Vite + React + TypeScript

---

## 1. 概要

L字テロップシステムの設定・管理・プレビューを行うSPAアプリケーション。7つのタブで構成され、L字テロップの全設定をビジュアルに操作可能。

---

## 2. 画面構成

```
┌─────────────────────────────────────────────────────────────┐
│  ⚙️ L字テロップ管理パネル                    [保存] [適用]   │
├──────┬──────┬──────┬──────┬──────┬──────┬──────────────────┤
│情報  │カラー│レイ  │エリア│データ│プレ  │ 詳細設定          │
│設定  │設定  │アウト│カラー│ビュー│ビュー│                   │
├──────┴──────┴──────┴──────┴──────┴──────┴──────────────────┤
│                                                             │
│                   各タブのコンテンツ                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### タブ一覧

| # | タブ名 | コンポーネント | 概要 |
|---|---|---|---|
| 1 | 表示情報設定 | `InfoSelector` | 表示する情報種別・地域の選択 |
| 2 | カラー設定 | `ColorSettings` | 警報レベル・震度別カラー設定 |
| 3 | レイアウト設定 | `LayoutEditor` | L字テロップのD&Dビジュアルエディタ |
| 4 | エリアカラー設定 | `AreaColorSettings` | 表示エリアごとの背景・文字色設定 |
| 5 | データビューア | `DataViewer` | 取得データの一覧・詳細表示 |
| 6 | プレビュー | `Preview` | テロップのリアルタイムプレビュー |
| 7 | 詳細設定 | `AdvancedSettings` | ポーリング間隔・音声等の詳細設定 |

## 3. タブ1: 表示情報設定 (`InfoSelector`)

### 3.1 情報種別選択

チェックボックス形式で表示する情報種別を選択。グループ化して表示する。

```
📋 表示する情報を選択

▼ 気象情報
  ☑ 気象特別警報・警報・注意報  [VPWW53/54/56/58/59/61]
  ☑ 気象情報（全般/地方）       [VPZJ50/VPCJ50]
  ☑ 竜巻注意情報               [VPHW50/51]
  ☑ 記録的短時間大雨情報        [VPOA50]
  ☑ 土砂災害警戒情報           [VXWW50]
  ☐ 指定河川洪水予報           [VXKOii]

▼ 地震・津波
  ☑ 震度速報                   [VXSE51]
  ☑ 震源・震度に関する情報      [VXSE53]
  ☑ 津波警報・注意報           [VTSE41]
  ☑ 津波情報                   [VTSE51]
  ☐ 長周期地震動情報           [VXSE62]

▼ 台風
  ☑ 全般台風情報               [VPTI50/51/52]
  ☑ 台風解析・予報情報          [VPTW60〜65]
  ☐ 台風の暴風域に入る確率      [VPTA50〜55]

▼ 火山
  ☑ 噴火警報・予報             [VFVO50]
  ☐ 降灰予報                   [VFVO53]
  ☐ 火山の状況に関する解説情報   [VFVO51]

▼ 天気予報
  ☐ 天気予報                   [VPFD50〜52]
  ☐ 天気概況                   [VPFG50]
  ☐ 週間天気予報               [VPFW50]
```

### 3.2 対象地域フィルタ

```
🗺️ 対象地域

[全国] [地方選択] [府県選択]

▼ 地方選択
  ☑ 北海道地方
  ☑ 東北地方
  ☑ 関東甲信地方
  ☑ 東海地方
  ☑ 北陸地方
  ☑ 近畿地方
  ☑ 中国地方
  ☑ 四国地方
  ☑ 九州北部地方
  ☑ 九州南部・奄美地方

フィルタは `PublishingOffice` の官署コードまたは `Area/Code` で照合する。

### 3.3 表示優先度設定

ドラッグ＆ドロップで情報種別の表示優先度を並び替え可能。

```
📊 表示優先度（上が高優先）

  ≡ 1. 緊急地震速報           [消去まで]
  ≡ 2. 津波警報・大津波警報    [消去まで]
  ≡ 3. 特別警報               [消去まで]
  ≡ 4. 震度速報               [300秒 ▼]
  ≡ 5. 津波注意報             [消去まで]
  ≡ 6. 気象警報               [600秒 ▼]
  ≡ 7. 台風情報               [600秒 ▼]
  ...
```

## 4. タブ2: カラー設定 (`ColorSettings`)

### 4.1 警報レベル別カラー

| レベル | 背景色 | 文字色 | カラーピッカー |
|---|---|---|---|
| 特別警報 | `#8B008B` | `#FFFFFF` | 🎨 |
| 警報 | `#FF2800` | `#FFFFFF` | 🎨 |
| 注意報 | `#FFD700` | `#000000` | 🎨 |
| 解除 | `#808080` | `#FFFFFF` | 🎨 |

### 4.2 震度別カラー

震度1〜7の各震度に対してカラーピッカーで設定。プリセット（気象庁標準色）をワンクリックで適用可能。

### 4.3 津波レベル別カラー

| レベル | 背景色 | 文字色 |
|---|---|---|
| 大津波警報 | `#B40068` | `#FFFFFF` |
| 津波警報 | `#FF2800` | `#FFFFFF` |
| 津波注意報 | `#FFD700` | `#000000` |

### 4.4 台風MAP用カラー

| 要素 | デフォルト色 |
|---|---|
| 暴風域 | `rgba(255, 0, 0, 0.3)` |
| 強風域 | `rgba(255, 255, 0, 0.2)` |
| 予報円 | `rgba(255, 255, 255, 0.5)` |
| 暴風警戒域 | `rgba(255, 0, 0, 0.15)` |
| 進路ライン | `#FFFFFF` |

### 4.5 プリセット

- **気象庁標準配色**: 気象庁HPに準拠したカラー
- **高コントラスト**: 視認性を高めた配色
- **ダーク**: 暗い背景向けの配色
- **カスタム保存**: 現在の設定をプリセットとして保存

### 5.1 ビジュアルD&Dエディタ

│  │                                                 │  │
│  │   各要素をドラッグして位置を調整                   │  │
│  │   要素の端をドラッグしてサイズを調整               │  │
│  │                                                 │  │
│  └─────────────────────────────────────────────────┘  │
│                                                        │
│  📦 配置可能な要素:                                      │
│  ┌──────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│  │左サイド│ │下部ティッカ│ │台風MAP   │ │出典表示  │     │
│  │バー   │ │ー        │ │         │ │         │     │
│  └──────┘ └──────────┘ └──────────┘ └──────────┘     │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐              │
│  │地震情報   │ │警報バッジ │ │時計表示  │              │
│  │パネル    │ │         │ │         │              │
│  └──────────┘ └──────────┘ └──────────┘              │
└────────────────────────────────────────────────────────┘
```

### 5.2 ドラッグ＆ドロップ要素

各要素は以下の操作が可能：

| 操作 | 方法 |
|---|---|
| 位置移動 | 要素をドラッグ |
| サイズ変更 | 要素の端・角をドラッグ |
| 回転 | 回転ハンドルをドラッグ（サイドバーの縦書き用） |
| プロパティ編集 | 要素をダブルクリックでプロパティパネルを表示 |
| 削除 | 要素を選択して Delete キー |
| ロック | 右クリック → ロック（誤操作防止） |

### 5.3 各要素のプロパティ

#### 左サイドバー

| プロパティ | デフォルト | 型 |
|---|---|---|
| x座標 | 0 | number (px) |
| y座標 | 0 | number (px) |
| 幅 | 100 | number (px) |
| 高さ | 1080 | number (px) |
| テキスト方向 | 縦書き | `vertical` \| `horizontal` |
| フォントサイズ | 48 | number (px) |
| 文字間隔 | 8 | number (px) |

#### 下部ティッカー

| プロパティ | デフォルト | 型 |
|---|---|---|
| x座標 | 0 | number (px) |
| y座標 | 1020 | number (px) |
| 幅 | 1920 | number (px) |
| 高さ | 60 | number (px) |
| フォントサイズ | 32 | number (px) |
| スクロール速度 | 80 | number (px/s) |
| スクロール方向 | 右→左 | `rtl` \| `ltr` |

#### 台風MAP

| プロパティ | デフォルト | 型 |
|---|---|---|
| x座標 | 200 | number (px) |
| y座標 | 100 | number (px) |
| 幅 | 600 | number (px) |
| 高さ | 500 | number (px) |
| 表示 | 台風情報受信時のみ | `auto` \| `always` \| `manual` |
| 地図タイル | OpenStreetMap | select |

### 5.4 スナップ・ガイド機能

- **スナップグリッド**: 10px単位でスナップ（ON/OFF切替可）
- **中心線ガイド**: 画面中央の十字線
- **要素間スナップ**: 他の要素と揃えるスマートガイド表示
- **セーフエリアガイド**: 放送セーフエリア（画面端から5%）の表示

### 8.3 テストデータ

ボタン1つで各種テスト情報を送信可能。各ボタンは気象庁のサンプルXML電文に基づくデータを使用する。

| ボタン | 送信されるテストデータ |
|---|---|
| 🌀 台風情報 | 台風5号の5日予報（位置・予報円・暴風域あり） |
| ⚠️ 警報 | 大雨警報（東京都） |
| 🔴 特別警報 | 大雨特別警報（全域） |
| 🔵 地震(震度4) | 震度4の地震情報 |
| 🔵 地震(震度6) | 震度6強の地震情報 |
| 🌊 津波警報 | 津波警報発表 |
| 🌋 噴火警報 | 桜島の噴火警報 |
| ⛈️ 竜巻注意 | 竜巻注意情報 |

### 8.4 プレビュー機能詳細

- **リアルタイム反映**: 設定変更がプレビューに即時反映
- **OBS出力プレビュー**: OBSで実際に表示される状態を再現（透明背景 + テロップのみ）
- **スクリーンショット**: 現在のプレビュー状態をPNG保存
- **アニメーション確認**: スクロール・フェード等のアニメーションをリアルタイム確認

## 9. タブ7: 詳細設定 (`AdvancedSettings`)

### 9.1 データ取得設定

| 設定項目 | デフォルト | 説明 |
|---|---|---|
| ポーリング間隔 | 60秒 | フィード取得間隔（最小60秒） |
| 取得フィード | 高頻度 | 高頻度 / 長期 / 両方 |
| CORS プロキシ URL | (空) | 必要に応じてCORSプロキシURLを設定 |
| タイムアウト | 10秒 | HTTP通信タイムアウト |
| リトライ回数 | 3回 | 取得失敗時のリトライ回数 |

### 9.2 自動消去タイマー

## 10. 設定の永続化

### 10.1 ストレージ方式

```typescript
// localStorage キー構造
{
  "l-telop-config": {
    version: "1.0",
    info: { /* InfoSelector設定 */ },
    colors: { /* ColorSettings設定 */ },
    layout: { /* LayoutEditor設定（各要素の位置・サイズ） */ },
    areaColors: { /* AreaColorSettings設定 */ },
    advanced: { /* AdvancedSettings設定 */ }
  }
}
```

### 10.2 設定の同期

- overlay.html は `localStorage` を定期的に監視（500ms間隔）
- 管理パネルでの設定変更は即時に `localStorage` に保存
- overlay.html は変更を検知してリアルタイムに反映
